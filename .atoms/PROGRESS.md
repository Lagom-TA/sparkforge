# Requirements & Progress

## Requirements Overview
完成 SparkForge 从 Next.js/Supabase 到 React + Vite/shadcn/ui/Atoms Cloud 的端到端迁移、优化、验证与上线准备。

## User Stories
- 用户可以登录后创建、查看和管理自己的 AI 应用项目。
- 用户可以提交需求，查看 AI 规划，批准后生成可预览、可查看源码的应用版本。
- 用户可以根据反馈继续优化项目并保留版本历史。
- 用户可以创建或撤销只读分享链接。
- 用户可以在不同设备上清晰、安全地完成核心流程。
