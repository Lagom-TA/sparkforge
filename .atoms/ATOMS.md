# Project Context

## Project Overview
将现有 SparkForge Next.js/Supabase 原型迁移为 React + Vite + shadcn/ui + Atoms Cloud 的 AI 应用生成平台，保留认证、项目工作区、规划审批、代码生成、结构化预览、版本历史与分享能力。

## Constraints
- Active theme: 暖白对话式 Product 主题
- 设计：参考 Codex、Claude Code 与 Notion；暖白画布、近黑文字、克制蓝色操作态、细边框；首页直接呈现需求输入框，项目列表和工作台均为次级功能
- 交互：AI 对话是一级信息架构；规划、构建、预览、源码和版本作为对话过程中的产物与工具面板出现
- 不修改系统保护的后端启动、核心配置和自动生成模型文件
- 不使用外部 LLM 密钥；AI 仅通过 Atoms Cloud 内置能力调用
- 生成内容必须持久化，并提供错误、空白、加载和重试状态
- Images to Generate：无需生成；产品以编辑器、对话和真实应用预览为核心
