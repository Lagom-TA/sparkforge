# SparkForge 项目介绍

SparkForge 是一个面向数据管理类应用的 AI 构建工作台。用户从一句自然语言需求出发，在可编辑蓝图中确认产品设计，再通过工作区查看构建进度、应用预览和源码产物。

产品将“说清需求、确认设计、查看产物、管理数据”放在同一个界面中，适用于任务管理、记录整理等围绕结构化数据展开的场景。

## 产品体验

### 从想法到产品蓝图

用户可以直接描述应用目标、字段和操作方式。Planner 将需求整理成结构化产品蓝图，用户可以在构建前编辑和确认，让数据结构与功能安排清晰可见。

### 对话与产物并排呈现

工作区集中展示对话、任务时间线、蓝图、应用预览和源码。暂停、恢复、停止与版本浏览都有对应的操作入口，便于在迭代过程中调整需求、检查结果。

### 围绕数据组织应用

预览组件根据应用规格呈现集合、表单和统计，提供记录新增、编辑、删除、搜索与状态筛选。数值字段支持小数输入，表单在操作失败时保留填写内容，减少重复输入。

### 分享与个性化设置

应用设计可通过只读快照分享，分享链接支持撤销。用户可以切换预览设备、调整紧凑布局和减少动效，个人偏好会持久保存。

## 实现思路与关键取舍

**将规划与构建分成两个阶段。** Planner 生成 ProductSpec，Builder 根据确认后的蓝图生成 AppSpec 与源码文件。两阶段分工使需求确认成为明确的产品步骤，也为后续迭代保留结构化依据。

**用结构化规格驱动界面。** AppSpec 描述数据集合、字段和视图，React 组件负责渲染交互。统一的规格让表单、筛选、统计与数据校验共享清晰的契约，也便于扩展新的字段和视图。

**把交互细节纳入状态设计。** 构建前保存已确认蓝图，使用运行标识隔离迟到响应，并对重复提交、输入法确认、历史版本只读等场景作专门处理。用户操作、任务状态与产物展示围绕同一套流程组织。

**复用 Atoms 的平台能力。** React、TypeScript 与 Vite 构成前端，FastAPI 承担接口与业务校验，Atoms 提供认证、云端数据和模型服务接入。后端统一检查所有权、字段类型和实体关联，分享接口提供精简的只读快照。

## 已实现的功能模块

| 模块 | 内容 |
| --- | --- |
| 需求与规划 | 对话输入、产品蓝图生成、蓝图编辑与确认 |
| 构建工作区 | 双模型分工、任务时间线、暂停恢复、停止、源码查看 |
| 应用预览 | 表单、数据集合、搜索筛选、统计、设备预览 |
| 项目与版本 | 项目持久化、历史版本浏览、只读历史预览 |
| 分享与设置 | 可撤销分享链接、紧凑布局、减少动效、偏好保存 |
| 工程质量 | 类型检查、Lint、生产构建、23 项后端与 8 项前端本地回归测试 |

## 后续演进方向

1. **构建体验**：推进后台任务执行、进度追踪和任务恢复，让更复杂的构建过程具有清晰的进度反馈。
2. **数据与协作**：扩展分页、数据结构演进和协作场景，丰富项目管理与版本操作。
3. **应用表达力**：增加字段类型、视图组件和场景模板，覆盖更多业务工具的构建需求。

优先打磨核心构建流程，再扩展数据能力和应用场景，让每一轮迭代都能直接改善用户从需求到产物的体验。
